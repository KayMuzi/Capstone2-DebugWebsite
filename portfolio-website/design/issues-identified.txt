Issues Identified

HTML Issues
Missing lang attribute on the <html> element.
Missing <meta charset="UTF-8"> metadata.
Missing responsive viewport meta tag.
Missing descriptive page metadata.
Generic <div> elements were used instead of semantic HTML5 elements.
Missing <header> structure.
Missing navigation menu across the pages.
Missing <main> elements for primary content.
Missing <section> elements to organise related content.
Missing <footer> semantic structure.
Images were missing descriptive alt text.
The About page was missing the required data table.
The Projects page was missing a third project.
Form controls did not have associated labels.
The email field incorrectly used type="text" instead of type="email".
The form lacked sufficient input/control types.
HTML5 form validation attributes were missing.
The submit button did not explicitly specify type="submit".

CSS Issues
Navigation styling was missing.
:hover and :focus states were missing from interactive elements.
Images lacked responsive sizing and display rules.
Table styling was missing.
Form styling was incomplete.
The layout lacked responsive design rules.
CSS organisation and commenting were limited.
Approach to Fixing the Issues

The website was rebuilt using semantic HTML5 elements and a consistent structure across all four pages. Accessible navigation, descriptive image alternative text, a structured data table, additional project content and a fully labelled contact form were added. HTML5 validation attributes and appropriate input types were also implemented.

The CSS was reorganised using consistent selectors, naming and indentation. Responsive layouts, navigation, table and form styling, accessible colour choices, focus states and hover effects were added. Flexbox and CSS Grid were used where appropriate, along with the CSS box model to create a consistent and responsive layout.
